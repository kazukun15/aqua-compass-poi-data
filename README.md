# AQUA COMPASS 地域POIデータ

## 四国抽出・部分収録

このリポジトリの地域POIは、[OpenStreetMap](https://www.openstreetmap.org/copyright) の公開データを基に、[Geofabrikの四国抽出](https://download.geofabrik.de/asia/japan/shikoku.html)から作成したものです。データの基準時刻は2026年10月27日 21:23:59 UTCです。地図データの著作権は OpenStreetMap の貢献者に帰属します。

**© OpenStreetMap contributors** — データは [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/) の条件に従って利用できます。出典・帰属・派生データベースの取り扱いについては[OSM Foundationの帰属ガイド](https://osmfoundation.org/wiki/Attribution_Guidelines)も参照してください。

`catalog.json` は、配布パッケージの版、SHA-256、サイズ、矩形およびGeofabrik公式抽出境界を記録します。矩形や境界内の全施設を網羅するという意味ではありません。この公開データは全国対応ではありません。地域の名称や境界は、現実の営業状況や最新性を保証しません。

車両進入を禁止・制限する明示的なタグや、車以外の専用と判断できる駐車場を保守的に除外しています。ただし、元データが不足している施設もあります。名称やアクセスが不明の場合は不明のままです。施設座標は近似位置であり、入口、敷地内の地点、駐車場の空き、営業時間、車両での進入可否を保証しません。実際の標識や現地の状況に従ってください。

パッケージは公開OSM由来の施設データのみで、走行履歴・目的地履歴・APIキー・アプリのソースコードは含みません。`verification.json` には件数と出典等を記録しています。
