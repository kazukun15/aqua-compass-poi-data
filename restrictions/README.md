# AQUA COMPASS 月次交通規制・先行配信

岡山県・広島県・愛媛県の3県を対象に、[JARTICの交通規制情報](https://www.jartic.or.jp/service/opendata/) K_2.1 をAQUA COMPASSが抽出・加工しています。先行配信用の参考情報であり、現在の交通規制、通行可否、公式の判断は示しません。出典・原本取得日・原本と生成ファイルのSHA-256は各版のメタデータに記録します。[JARTIC利用規約](https://www.jartic.or.jp/d/opendata/riyou_kiyaku.pdf)

UTC 00:37（日本時間09:37）を目安に公式目録を日次で確認し、版が変わった場合のみ地域のZIPを取得します。検証に成功した版だけを公開し、更新の遅延・原本不足・通信障害時は前版の配信を続けます。アプリ利用者の位置・経路・設定はこのリポジトリや更新処理に含まれません。

対象は通行止め、車両通行止め、一方通行、指定方向外進行禁止、車両進入禁止の登録データです。今回の端末照合は、方向・時間・対象条件の明確な一方通行と指定方向外進行禁止に限定しています。道路標識・現地規制を優先してください。
